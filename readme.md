Support:
How frequently a rule appears in the dataset
Support(A → B) = P(A ∩ B)

Confidence:
Probability of B occurring given A
Confidence(A → B) = P(B | A)

Lift:
How much more likely A and B occur together compared to chance
Lift(A → B) = P(A ∩ B) / (P(A) \* P(B))
